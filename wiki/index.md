# Wiki Index

This wiki is a four-layer navigation graph — question-patterns → MOCs → concept pages → raw book chapters — for grounding expert-level software-architecture answers.

## Start here

For any non-trivial expert question — extract-a-service, scale-10x, pick-a-style, design event-driven communication, adopt SLOs, resolve Conway-friction, choose a database, evolve a schema, build a data platform, secure a data platform, respond to cascading failure — begin with **[[question-patterns]]**. It routes each archetype to the MOCs and concept pages that compose to a grounded answer. Read every MOC the chosen pattern lists before drafting.

For targeted lookups (a single concept by name), jump straight to the **A–Z appendix** at the bottom.
